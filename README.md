# STM32-FreeRTOS-MultiInstrument

基于 **STM32F103RCT6** 和 **FreeRTOS** 的多功能电子测量仪项目。

这是一个边学习边开发的嵌入式项目，计划逐步实现数字万用表、简易示波器和逻辑分析仪等功能，同时记录 STM32 外设、FreeRTOS 和硬件调试过程。

> 项目目前处于学习与开发阶段，功能和技术方案会持续调整。

## 项目目标

- [ ] 数字万用表：实现基础电压、电阻等测量功能
- [ ] 简易示波器：采集并显示输入信号波形
- [ ] 逻辑分析仪：采集并观察数字信号
- [ ] 屏幕显示与按键交互
- [ ] 使用 FreeRTOS 管理任务及任务间通信
- [ ] 整理电路、软件设计和调试文档


## 硬件与开发环境

| 项目 | 内容 |
| --- | --- |
| 主控芯片 | STM32F103RCT6 |
| 操作系统 | FreeRTOS |
| 开发语言 | C |
| 开发工具 | STM32CubeIDE、STM32CubeMX |
| 调试工具 | ST-Link、串口助手等 |
| 屏幕 | ST7789VI |

## 技术学习

项目开发过程中涉及：

- STM32 GPIO、中断、定时器、ADC 和 DMA
- UART、SPI、I2C 等通信接口
- FreeRTOS 任务、队列、信号量和内存管理
- LCD 显示、按键交互及硬件调试

具体使用情况以当前代码和开发日志为准。

## 获取与运行

1. 下载或克隆本仓库。
2. 使用 STM32CubeIDE 导入对应工程。
3. 检查芯片型号、工程配置和硬件连接。
4. 编译后，通过 ST-Link 烧录到开发板。

> 目前项目仍在整理，具体的工程目录、编译版本和接线说明会随项目完善后补充。

## 开发日志

- **阶段一：** 学习 STM32 基础外设和通信协议。
- **阶段二：** 学习 FreeRTOS 任务调度及任务间通信。
- **阶段三：** 调试 LCD、按键和蜂鸣器等基础功能。
- **后续计划：** 完成信号采集、波形显示及测量功能。
